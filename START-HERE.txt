READY TO HOST
Publish the contents of dist/ as your static website. It includes the homepage,
pricing, how-it-works and photo credits pages. There is no build step.
Local preview: run python3 -m http.server 8000 --directory dist
then open http://localhost:8000 in your browser.

EDITING
Shared page content: scripts/build-pages.py
Styles: dist/experience.css
Menus, previews and inquiry form: dist/app.js
Scrolling: dist/experience.js
Page-loading animation: dist/transitions.js
After editing content, CSS or JavaScript, run python3 scripts/build-pages.py
from this extracted folder to regenerate pages and asset fingerprints.
